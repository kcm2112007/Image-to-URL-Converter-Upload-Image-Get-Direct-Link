Frequently asked questions

What is an image URL?

An image URL is a direct HTTPS link that points straight to an image file. Browsers and apps can load and display it without opening a webpage first.

How do I convert an image to a URL?

Upload the image using the tool above. It's sent to the configured storage provider, which returns a permanent public link you can copy.

Can I use the generated URL in HTML?

Yes — paste it into an <img> tag's src attribute.

Can I use the image URL in CSS?

Yes, inside a background-image property, e.g. background-image: url("YOUR_IMAGE_URL");.

Can I use it in Markdown?

Yes, using standard Markdown image syntax: ![Description](YOUR_IMAGE_URL) — this also works in a GitHub README.

Are generated URLs public?

Yes. Anyone who has the URL can view the image. Don't upload anything you don't want to be publicly accessible.

How long do image URLs remain available?

URLs are intended to be permanent for as long as the storage account and file remain active. This depends on your storage provider's own account limits and policies.

Can I delete an uploaded image?

Deletion needs privileged storage credentials that can't safely live in browser code, so it requires a small server-side endpoint. This build doesn't currently expose a delete feature.

Is there a file size limit?

Yes — 10 MB per image by default, and 20 images per bulk batch. You can change these at the top of script.js.

Does Image To URL work on mobile?

Yes. The tool is fully responsive and supports picking images from a phone's camera or photo library.

Are my images private?

No. Public image hosting means the resulting URL is reachable by anyone who has it, the same as any public CDN link.

Developer documentation

Using the URL

Every uploaded image gets one direct, permanent HTTPS URL. Paste it anywhere that accepts an image link:

<img src="YOUR_IMAGE_URL" alt="Description">
background-image: url("YOUR_IMAGE_URL");
![Description](YOUR_IMAGE_URL)
const image = "YOUR_IMAGE_URL";

Public URLs, hotlinking & caching

A generated URL is publicly reachable by anyone who has it — that's what makes it usable in HTML and CSS in the first place. You can hotlink it directly from any website or app. Storage-provider CDNs cache aggressively, so a fresh upload should use a new public ID rather than reusing an old one.

File formats & limits

JPG, PNG, WebP, GIF and AVIF are supported. SVG is disabled by default because SVG files can contain executable script content. Bandwidth and storage are governed by your storage provider's plan — this tool does not provide unlimited bandwidth.

Coming soon

Not implemented yet, listed here so it's clear what's planned: a REST upload API, API keys, signed uploads, webhooks, on-the-fly transformations, and a usage dashboard.

Technology used

Plain HTML, CSS and vanilla JavaScript — three files total, deployable straight to GitHub Pages. Image storage and delivery is handled by Cloudinary via an unsigned upload preset. The QR code is generated in-browser by the qrcode.js library.

Privacy

Images uploaded through this tool are stored by the configured image-storage provider and may be publicly accessible through their generated URL. Anyone who has the URL can view the image. Do not upload images you want to keep private.

Upload history (filename, URL and date) is saved only in your browser's local storage, on your device — never on a server. Clearing your browser's site data removes it. No analytics or tracking cookies are included in this build.

Terms of use

Don't upload images you don't have the right to share, or content that is illegal or infringing. Uploaded images pass through to a third-party storage provider and are also subject to that provider's own acceptable-use policy. This tool is provided as-is, with no guarantee of unlimited bandwidth or uptime beyond what your storage provider allows. Features marked "Coming Soon" are not yet available.
