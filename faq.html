Frequently asked questions

What is an image URL?

An image URL is a direct HTTPS link that points straight to an image file. Browsers and apps can load and display it without opening a webpage first.

How do I convert an image to a URL?

Upload the image using the tool on the homepage. It's sent to the configured storage provider, which returns a permanent public link you can copy.

Can I use the generated URL in HTML?

Yes — paste it into an <img> tag's src attribute.

Can I use the image URL in CSS?

Yes, inside a background-image property, e.g. background-image: url("YOUR_IMAGE_URL");.

Can I use it in Markdown?

Yes, using standard Markdown image syntax: ![Description](YOUR_IMAGE_URL) — this also works in a GitHub README.

Are generated URLs public?

Yes. Anyone who has the URL can view the image. Don't upload anything you don't want to be publicly accessible.

How long do image URLs remain available?

URLs are intended to be permanent for as long as the storage account and file remain active. Ultimately this depends on the storage provider's own account limits and policies.

Can I delete an uploaded image?

Deletion needs privileged storage credentials that can't safely live in browser code, so it requires a small server-side endpoint. This deployment doesn't currently expose a delete feature.

Is there a file size limit?

Yes — 10 MB per image by default, and 20 images per bulk batch. The site owner can change these limits in configuration.

Does Image To URL work on mobile?

Yes. The tool is fully responsive and supports picking images from a phone's camera or photo library.

Are my images private?

No. Public image hosting means the resulting URL is reachable by anyone who has it, the same as any public CDN link.
