Developer documentation

Everything you need to use a generated Image To URL link in your own code.

Using the URL

Every uploaded image gets one direct, permanent HTTPS URL. Paste it anywhere that accepts an image link:

HTML

<img src="YOUR_IMAGE_URL" alt="Description">

CSS

background-image: url("YOUR_IMAGE_URL");

Markdown / GitHub README

![Description](YOUR_IMAGE_URL)

JavaScript

const image = "YOUR_IMAGE_URL";

Public URLs

A generated URL is publicly reachable by anyone who has it. There is no login check on the image itself — that's what makes it usable in HTML, CSS, and other tools in the first place. Don't upload anything you don't want to be publicly accessible.

Hotlinking

You can reference the URL directly (hotlink) from any website, app, or document. The image is served from the storage provider's CDN, not from this site's own server.

Caching

Storage-provider CDNs cache aggressively for speed. If you re-upload a file under the same public ID, some viewers may keep showing a cached copy for a while — use a new public ID for a guaranteed-fresh URL.

URL stability

URLs are intended to be permanent for as long as the underlying storage account and file exist. This tool does not control the storage provider's own retention policies — check your provider's dashboard for account-level limits.

File formats

JPG, PNG, WebP, GIF and AVIF are supported for upload. SVG is disabled by default because SVG files can contain executable script content; an operator can enable it only after adding their own sanitization.

Usage limitations

Bandwidth and storage are governed by whatever plan the site owner has with their storage provider — this tool does not provide unlimited bandwidth, and heavy traffic on a free-tier account may be throttled or billed by the provider.

Technology & services used

This site is a static frontend (HTML, CSS, vanilla JavaScript) deployable on GitHub Pages. It relies on the following external services to work:

  • Cloudinary — image storage and CDN delivery, via an unsigned browser upload preset.
  • qrcode.js (loaded from cdnjs) — generates the downloadable QR code for a URL, entirely in the browser.
  • Google Fonts — Space Grotesk, Inter and JetBrains Mono.

No analytics are enabled by default. If the site owner turns analytics on, it will be documented on the Privacy page.
